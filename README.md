# 创世纪元：AI 文明诞生概率实验室

第十四届全国大学生数字媒体科技作品及创意竞赛参赛作品 · 指定命题「科幻+及元宇宙数字作品」

一场文明探索体验：你在 AI 运行的实验室里亲手孕育、见证、失去一个又一个文明。你对规律的认识，决定你能改变宇宙的哪一层；人类文明，是所有钥匙恰好都拧对的那一次；而未来的钥匙，握在每一个人手里。

## 直接运行

- **评委与观众**：双击 `dist/index.html`。这是一个单文件（约 1.5 MB），脚本、字体与贴图全部内联，离线可运行，不需要安装任何软件。推荐使用新版 Chrome 或 Edge，桌面全屏，佩戴耳机。
- 导览模式约 5 分半，自动走完全部章节；自由探索可以在每个实验舱里调参、重来。
- 详细操作见 [docs/操作说明.md](docs/操作说明.md)。

## 开发

需要 Node.js 20 以上。

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

| 命令 | 作用 |
|---|---|
| `npm run dev` | 本地开发服务器（热更新） |
| `npm test` | 运行全部单元测试（公式、引擎、校验闸门、离线问答） |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run build` | 类型检查后构建单文件 `dist/index.html` |
| `npm run docs` | 从源码重新生成数据类文档（参数表、旁白文稿、知识卡、理论对照、离线问答、关键数值） |
| `npm run fonts` | 按源码实际用到的字符重新子集化字体（需要 `assets-src/` 中的源字体与 Python fonttools） |

预览参数：在地址后加 `?speed=4` 可以 4 倍速播放导览，用于排练与检查，正式演示不要加。

## 目录

```
src/
  sim/      确定性推演引擎：公式、参数注册表的判定、恒温器、K-Pg、文明动力学、未来模型、蒙特卡洛、Lorenz、因果图
  data/     参数注册表（含出处与置信等级）、旁白文稿、顿悟卡、知识卡、理论库、离线问答、编年史片段
  llm/      观测者·零号：OpenAI 兼容接口、校验闸门、检索增强、离线兜底
  render/   Three.js 场景：程序化行星、浑天仪、宇宙网、银河系、恒星系、撞击体、双环、万宇宙
  acts/     序章与五幕、终章：每一幕的场景、仪器面板与导览脚本
  app/      全局状态、应用总装、章节导演
  ui/       界面：顶栏与文明链条、仪器面板、弹窗、观测档案、墓园、设置、启动页
  audio/    Web Audio 生成式声音
  assets/   子集化字体与 NASA 公有领域地球影像
tests/      单元测试（Vitest）
scripts/    字体子集化、文档生成
docs/       作品说明、AI 使用说明、知识产权声明、操作说明、技术路线、审校清单等
licenses/   第三方许可证全文
```

## 关于人工智能工具

本作品的方向与审定由学生团队负责，设计方案起草与代码实现使用了 AI 编程助手 Claude（Anthropic）。运行时可接入大模型担任“观测者·零号”，所有数值由确定性引擎计算。详见 [docs/人工智能工具使用说明.md](docs/人工智能工具使用说明.md)。
