# 技术路线说明

## 一、总体架构

```
体验层   acts/（序章、五幕、终章）  app/Director（章节切换、导览与自由模式）  ui/（面板、弹窗、档案）
   │ 状态                                   ▲ 事件
表现层   render/（Three.js 场景、着色器、泛光、自适应画质）  audio/（Web Audio）
   │                                        ▲ 状态与事件日志
模拟层   sim/（确定性推演引擎，纯函数，有单元测试）
   ▲ 参数提议须通过校验闸门                  │ 引擎结果与出处
智能层   llm/（Provider 抽象、意图解析、检索增强、离线兜底、内容标识）
数据     data/（参数注册表、理论库、知识卡、旁白、离线问答、编年史片段）
```

设计原则：

1. **确定性内核**：模拟层不依赖界面与渲染，同样的参数与宇宙编号得到同样的结果，可测试、可复现。
2. **LLM 提议，模型裁决**：智能层只能通过校验闸门向模拟层提交参数提议，不能直接写入数值。
3. **一份数据，多处使用**：参数注册表同时驱动界面滑杆、引擎判定、LLM 校验、观测档案与文档生成（`npm run docs`）。

## 二、模拟层（`src/sim/`）

| 模块 | 内容 | 关键公式或方法 |
|---|---|---|
| `formulas.ts` | 平衡温度、质光关系、主序寿命、宜居带、逃逸速度、温室增温、卡尔达肖夫指数 | T_eq = [L★(1−A)/(16πσa²)]^¼；L ∝ M⁴（0.43–2 M☉）；t ≈ 10 Gyr·M/L；d = √(L/S_eff)，S_eff = 1.015 / 0.356 |
| `universe.ts` | L0–L3 逐层判定，每项检查给出状态、结论、解释与引用的参数编号 | 霍伊尔窗口 ±0.5% × ±4%；Λ 示意阈值 100 倍；一阶液态水窗口与文献宜居带的交叉判定 |
| `thermostat.ts` | 碳–硅酸盐循环稳态与扰动 | W = W₀·(pCO₂/p₀)^0.3·exp((T−288)/13.7)，T = T_eq + 33 + 3·log₂(pCO₂/p₀)；稳态 V = W 用二分法求解；扰动在对数空间弛豫 |
| `kpg.ts` | 撞击沉积区 | 9 个确定性球冠，用 4 万个固定采样点估计并集面积，二分标定到地表 13% |
| `civ.ts` | L4 文明动力学（示意性模型） | P 增长受 R 拖慢；C = (P−R)/R 越过 0.6 即社会形态更替；E 随生产力累积、被生态约束削减；工业化后风险 ∝ (1−合作)^1.2 |
| `future.ts` | L5 未来情景模型与历史合力 | 每十年一步、共一千年的风险分解；人群选择的平均即合力；四维选择投影为平面力向量 |
| `montecarlo.ts` | 万宇宙德雷克方程抽样 | 各因子对数均匀分布；f_l = 1 − exp(−λVt)，log₁₀λVt ~ N(0, 50) |
| `lorenz.ts` | 双轨迹与增长率拟合 | 四阶龙格–库塔，步长 0.005；最大李雅普诺夫指数约 0.906 |
| `causal.ts` | 因果图与参数空间存活比例 | 下游传播用于“因果涟漪”；在滑杆取值范围内抽样 12000 次统计逐层通过比例 |

模型参数与出处见 [参数与文献](参数与文献.md)，计算结果见 [关键数值](关键数值.md)。

## 三、智能层（`src/llm/`）

1. **提议**（`observer.ts` 的 `PLANNER`）：系统提示词包含注册表摘要，要求只输出 `{"intent","changes","rationale"}` JSON。
2. **校验闸门**（`schema.ts`）：参数必须在注册表中、不能是只读事实、类型正确、在范围内（越界夹回并标注）、观众持有对应钥匙；一次最多 4 项。
3. **沙盒推演**（`observer.ts` 的 `sandbox`）：在副本上运行引擎，得到逐层结论；涉及 L4 时同时给出 300 个平行宇宙的存活率。不影响当前旅程。
4. **检索增强解释**（`rag.ts` 与 `EXPLAINER`）：按字符二元组重合度检索知识卡、理论库与相关参数；提示词要求数值只能来自引擎结果，理论只能引用库内原文。
5. **离线兜底**（`data/offline.ts`）：21 条规则意图与预置回答，带调参的条目同样经过校验闸门与沙盒。
6. **Provider**（`provider.ts`）：OpenAI 兼容的 `chat/completions`，30 秒超时；Key 只存本机浏览器。

## 五、体验层

- **章节导演**（`app/Director.ts`）：切换中收到的跳转请求排队执行；导览模式按 `ACT_ORDER` 依次进入每一幕并运行其 `guided()` 脚本；中途退出时以自由模式重新进入当前幕，完整结束时保留终章画面。
- **补间与时间**（`core/tween.ts`）：所有动画与导览等待都由渲染循环驱动的补间调度器执行，因此暂停、倍速与跳过对整条时间线一致生效。
- **认知等级与钥匙**（`app/state.ts`）：钥匙集合驱动浑天仪、滑杆锁定与校验闸门；参数改动触发因果涟漪动画。

## 六、性能与兼容

- 粒子数量按档位缩放：宇宙网 6 万 / 3.3 万 / 1.7 万，银河系 4.2 万 / 2.3 万 / 1.2 万，星空 5000 / 2750 / 1400。
- 像素比上限：高档 2、中档 1.25、低档 0.85。
- 移动端默认低档；窄屏界面改为底部面板。
- 开发机实测：桌面独立显卡约 140 fps（中档）。集成显卡与移动端【待团队实测记录】。

## 七、测试与构建

- `npm test`：47 项单元测试，覆盖公式数值（地球 T_eq ≈ 254.6 K 等）、逐层判定、恒温器负反馈、13% 标定、文明模型可复现性与单调性、未来模型解析解与蒙特卡洛一致、Lorenz 增长率、校验闸门全部拒绝规则、离线意图匹配。
- `npm run build`：类型检查后用 Vite 与 vite-plugin-singlefile 构建，字体（woff2 子集）与影像以 data URI 内联，输出单个约 1.5 MB 的 `dist/index.html`，运行时零网络请求。
- 字体子集化：`scripts/build-fonts.py` 扫描源码中实际出现的字符，思源宋体子集约 370 KB，JetBrains Mono 子集约 30 KB。

## 八、与设计案的差异

| 设计案 | 实际实现 | 原因 |
|---|---|---|
| GSAP 时间轴 | 自写补间调度器 | 减少第三方依赖与授权条款核对；便于统一暂停与倍速 |
| postprocessing 库 | three.js 自带 UnrealBloomPass | 功能足够，减少依赖 |
| 连续缩放到城市灯光（10⁴ m） | 缩放到行星尺度（10⁷ m），城市灯光以行星着色器呈现 | 工期内优先保证完整闭环，列为计划中 |
| 参数敏感度龙卷风图 | 未实现 | P1，列为计划中 |
