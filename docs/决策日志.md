## 实现阶段的技术决策（2026-10-07，由 AI 提出，团队已审定）

| 议题 | 决定 | 理由 |
|---|---|---|
| 动画库 | 不用 GSAP，自写补间调度器 | 减少依赖与授权核对；导览的暂停、倍速、跳过统一生效 |
| 后期 | 使用 three.js 自带泛光 | 足够，减少依赖 |
| 地球影像 | 终章使用 NASA 公有领域昼夜影像 | “这是此刻的地球”需要真实可辨的地球 |
| 字体 | 思源宋体子集与 JetBrains Mono 子集内嵌，正文用系统字体 | 离线可用；控制单文件体积 |
| 默认推演中的失败 | 默认推演只作演示，不计入墓园；观众自己的推演失败才计入 | 避免墓园被演示记录填满 |
| 星辰之钥 | 所有认知等级都持有，第②幕的默认推演改为“已持有钥匙”的顿悟卡 | 所有学段都学过太阳系与水的三态 |
| “另一个你” | Lorenz 双轨迹加相邻宇宙编号的两个文明对比 | 文明模型本身不是强混沌系统，用数学与随机历史两种方式分别呈现蝴蝶效应 |
| 未来模型 | 千年存活率按风险分解的情景模型，明确标注为示意 | 表达方向与相对大小，避免伪精确的预测 |
| 第⑤幕改为微观文明沙盘（2026-10-07，团队审计意见） | 用基于主体的模型取代三维双环：聚落、商路、战争、瘟疫与政体的生产力 / 生产关系在沙盘上涌现；双环曲线保留在面板中显示世界平均 | 审计意见：“缺少实时可更改的数据，缺少微观的人类文明推演可视化，交互性不强” |
| 宏观与微观两套文明模型并存 | 宏观双环模型作为平均场近似，用于 500 个平行宇宙的快速估计与“另一个你”；微观沙盘用于体验与可视化，并提供后台微观抽样 | 微观模型单次推演约 0.3 秒，无法实时做 500 次；两者趋势一致由单元测试校验 |
| 全局参数台与实时读数（2026-10-07） | 顶栏新增参数台，任何一幕都能调节全部参量；文明链条默认显示实时读数；实验大厅加入宇宙仪表与两个快捷滑杆，行星外观随判定变化 | 同一条审计意见：从第一屏开始就能“改一个参量，看见世界改变” |
| 核危机的叙事 | 低合作的默认推演中，前两次危机由个人克制化解，第三次仍然失控 | 表达个人的选择重要，但结构性的对立只能靠改变“合作”这一参量来消解 |
