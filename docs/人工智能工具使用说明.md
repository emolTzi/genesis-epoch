## 二、作品运行时使用的大模型（可选功能）

| 项目 | 内容 |
|---|---|
| 功能 | “观测者·零号”：把观众的自然语言问题翻译成参数提议；把引擎推演结果讲成人话；在线模式下为新文明取名 |
| 接入方式 | OpenAI 兼容接口，由观众在设置中填写服务地址、模型与 API Key（作品不内置任何 Key）。预置选项：DeepSeek、通义千问、智谱 GLM、Kimi，均为国内服务；具体选用哪家【待团队确定】 |
| 系统提示词 | 见源码 `src/llm/observer.ts` 中的 `PLANNER`、`EXPLAINER` 与取名提示词 |
| 约束 | 大模型输出的参数提议必须通过校验闸门（`src/llm/schema.ts`）：参数必须在注册表中、类型正确、落在范围内（越界夹回并说明）、观众持有对应钥匙。所有数值由确定性引擎计算，解释时只能引用引擎结果与资料库，理论问题只能引用理论库中的标准表述 |
| 离线兜底 | 没有网络或 Key 时，使用规则意图解析与预置回答（`src/data/offline.ts`），不调用任何大模型 |

## 三、生成合成内容的标识

| 内容 | 来源 | 界面标识 |
|---|---|---|
| 在线模式下观测者的回答 | 大模型实时生成 | “AI 生成” |
| 在线模式下的文明名字 | 大模型实时生成 | 文明链条中注明“名字由 AI 生成” |
| 离线模式下观测者的回答 | AI 辅助撰写、团队审校的预置文本 | “离线缓存 · AI 辅助撰写” |
| 离线文明名字 | 程序按宇宙编号从字库组合 | “名字由程序生成” |
| 编年史片段、墓志铭 | AI 辅助撰写、团队审校的文本库，程序按宇宙编号选取 | 墓园与档案中说明 |
| 旁白、知识卡、顿悟卡 | AI 辅助撰写，团队审校 | 作品说明中披露 |

按《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）的要求，具体的显式与隐式标识格式以《作品材料提交规范》为准【待核对】。

## 四、版权与数据合规

- 作品不包含任何由 AI 生成的图像、音频或视频。地球影像为 NASA 公有领域资料，声音全部由 Web Audio 实时合成。
- 运行时不收集观众数据；墓园记录、留言与大模型配置只保存在观众本机浏览器中。API Key 默认只保存在当前会话。
- 不使用任何现有科幻作品的专有名词、角色与原文。
