# 答辩准备

总决赛由三名产业专家现场提问。下面的回答是要点，团队必须用自己的话讲熟，并能在作品中当场演示。答辩分的高低取决于团队是否真正掌握作品，这一项无法由 AI 代劳。

## 现场演示流程（约 3 分钟）

1. 双击 `dist/index.html`，说明“单文件、离线、零安装”。
2. 自由探索：认知校准选“观测员”。
3. 第②幕：拖动轨道到 2.4 AU，行星冰封，读出 T_eq 约 164 K；拖回 1 AU。
4. 第④幕：点击行星普通区域，人类未登场；点击橙色区域，大灭绝发生。
5. 第⑤幕：推演文明，在 1962 年选择“投反对票”；打开“另一个你”。
6. 打开观测者·零号，问“如果没有月球会怎样”，指出校验闸门与沙盒推演。
7. 打开观测档案的参数注册表，指出置信等级与出处。

## 问答

**物理常数微调能解释费米悖论吗？**
不能，常数处处相同。作品把问题拆成两个：常数回答“宇宙为何允许生命”（第①幕），行星、生命、文明这几层回答“银河系为何寂静”（第②–⑤幕与终章的蒙特卡洛）。

**“一个参量变了文明就不可能诞生”，是不是说过头了？**
作品的表述是“在已知物理定律与本模型假设下”。每条结论带出处与置信等级，示意阈值、争议内容都明确标注。两层叠加：参数离开可行区间，链条断裂；参数都在区间内，演化道路的偶然性也使“人类”这一具体结果不可复现。

**你们是在用模型证明马克思主义吗？**
不是。第⑤幕是以历史唯物主义为框架的示意性模型，用来把生产力与生产关系的矛盾运动可视化，不做历史预测，也不宣称证明。

**五种社会形态依次出现，是不是机械的单线论？**
标准表述体现普遍规律；社会发展道路具有统一性与多样性，平行文明可以呈现不同道路。可延伸到马克思晚年关于“卡夫丁峡谷”的论述与中国道路。模型中的毁灭风险只取决于技术水平与合作程度，与社会形态名称无关。

**蝴蝶效应与历史必然性矛盾吗？**
不矛盾。“另一个你”中，同参数的相邻宇宙结局可能完全不同，这是偶然；500 个平行宇宙的存活率随合作程度稳定上升，这是必然。必然性通过偶然性为自己开辟道路。

**LLM 会不会胡编数据？**
大模型只提议参数和组织语言。提议必须通过校验闸门：参数存在、类型正确、在范围内、观众持有钥匙。数值由确定性引擎计算，理论问题只能引用库内标准表述。没有网络时用离线规则与预置回答。

**团队做了什么，AI 做了什么？**
【团队按实际情况回答，对照决策日志、审校记录、测试记录、视频工程文件】作品的方向与六轮关键决策由团队提出；设计案起草与主要代码由 AI 编程助手 Claude 生成，已在 AI 使用说明中如实披露；审计、审校、配音、测试、视频与答辩由团队完成。

**和一般的科幻场景漫游、科普课件有什么不同？**
知识即权限：理解了才能改变。每一次失败都来自引擎的计算，可复现；每位观众得到独一无二、可复现的文明史。

**为什么用 Web 而不是 UE？**
可验证性与传播：评委零安装、双击即开、手机可看，单文件 1.5 MB；真实模型与离线 AI 在 Web 上更容易实现。画面通过着色器、HDR 泛光与美术指导弥补。

**数字“51.6%”“1/1.8×10⁵”是怎么来的？**
51.6% 是本模型下一万次德雷克方程抽样中 N < 1 的比例，区间为本作品设定，不代表论文结论。文明链条右侧的比例是在作品滑杆取值范围内抽样 12000 次、逐层通过的比例，依赖于取值范围的设定，界面上如实说明。全部数字见关键数值表。

**没有网络时怎么演示？**
整部作品离线可运行，观测者·零号自动切换到离线规则与预置回答；演示视频作为第二道兜底。

**作品怎么用、给谁用？**
科技馆展陈（导览模式循环）、高校通识与思政课（研究员与首席科学家等级）、中学科普（低等级）、网页传播与分享海报。【引用用户测试数据】

**和《三体》是什么关系？**
只受中国硬科幻宇宙哲学气质的启发，没有使用任何专有名词、角色与原文，世界观与命名全部原创。

**终章的千年存活率准吗？**
那是情景模型，用来表达四个参量的方向与相对大小，界面上标注为示意，不是预测。

**大卫星真的必要吗？**
学界有争议：Laskar 等认为无月地球倾角会混沌变化，Lissauer 等认为影响可能有限。作品因此只给警示、不判失败，并标注“争议”。
