# 操作说明

## 运行

1. 双击 `dist/index.html`，用新版 Chrome 或 Edge 打开（Firefox、Safari 也可以）。不需要网络，不需要安装。
2. 建议桌面浏览器全屏（F11），佩戴耳机。手机与平板可以打开，界面会切换为底部面板布局，画面效果会自动降档。
3. 启动页就绪后选择：
   - **导览模式**（约 5 分 10 秒）：自动走完序章到终章，字幕讲解，适合展陈与第一次观看。
   - **自由探索**：先做认知校准，然后在每个实验舱里自己调参、推演、重来。

如果画面无法显示，请确认浏览器已开启硬件加速（设置 → 系统 → 使用图形加速）。

## 界面

| 位置 | 内容 |
|---|---|
| 顶栏中间 | 当前章节（科学术语标题与宇宙层级）；宽屏时显示章节进度点，可点击回到已到达的章节 |
| 顶栏右侧 | 导览 / 自由探索切换、参数台、观测者·零号、观测档案、文明墓园、设置、声音 |
| 左侧“文明链条” | 你的文明名字与宇宙编号；L0–L5 每一层的状态（金色通过、紫色警示、红色失败）；右侧为实时读数（平衡温度、地表温度、文明存活率等，随参量即时变化），点击标题切换为“参数空间存活比例”；下方六段为六把钥匙 |
| 右侧仪器面板 | 当前实验舱的说明、参数滑杆、读数、推演结论与“进入下一幕”按钮 |
| 底部 | 观测者·零号的字幕；导览模式下有进度条、暂停、跳过本幕、退出导览 |

## 操作

| 操作 | 方式 |
|---|---|
| 旋转视角 | 在画面上拖动 |
| 缩放 | 滚轮 |
| 折叠 | 左侧文明链条、右侧仪器面板与事件流右上角都有折叠按钮；面板中的每个分节点击标题即可展开或收起（次要信息默认收起），选择会被记住；顶栏“收起”或 H 键一键收起全部，只留画面 |
| 调参 | 拖动右侧面板的滑杆；或打开顶栏“参数台”（快捷键 P），在任何一幕拖动全部参量，六层判定与行星外观立刻变化；带“需要某某之钥”提示的滑杆尚未解锁 |
| 解锁钥匙 | 点击“观看默认推演”，看到后果并读完顿悟卡后自动解锁 |
| 决定撞击点（第④幕） | 点击行星表面；橙色斜纹区域是富含碳氢化合物与硫的沉积区，约占地表 13% |
| 文明沙盘（第⑤幕） | 底部控制台：播放 / 暂停、1–8 倍速、时间轴；推演中随时拖动右侧的合作、生态约束、开放交流、制度弹性，历史立即改道 |
| 回溯改写 | 把底部时间轴拖回过去并松开：历史从那一刻重新推演，此后由新的参量书写；右侧曲线中的灰色虚线是原来那条分支 |
| 观察与干预 | 选择“观察”后点击聚落，查看它的人口、时代、社会形态与它自己的历史；选择“传授技术”“调停”“修复生态”“瘟疫”“大旱”后点击沙盘，直接干预 |
| 事件流 | 左侧列出战争、瘟疫、变革、结盟等事件，点击可飞到事发地点 |
| 核危机（第⑤幕） | 两个拥有核武器的政体开战时推演暂停，由你做出选择（原型为 1962 年 B-59 潜艇与 1983 年预警误报） |
| 另一个你（第⑤幕） | 点击“另一个你：蝴蝶效应”，比较初始只差百万分之一的两个世界 |
| 提问 | 打开“零号·提问”，输入问题或点击建议问题；在自由模式下可以把推演结果“在本宇宙中应用” |

键盘：空格 导览暂停/继续 · P 参数台 · Q 观测者·零号 · A 观测档案 · H 收起/展开全部面板 · Esc 关闭面板。

## 失败与重来

任何一层失败，文明熄灭并归入大厅外圈的文明墓园。可以选择“回溯到本幕开始”，或“换一个宇宙重新开始”（保留已解锁的钥匙）。宇宙编号即随机种子：在序章输入同一个编号，会得到同一部编年史与同一个结局。

## 接入大模型（可选）

不配置也能完整体验。需要自由提问时：设置 → 观测者·零号：接入大模型 → 选择服务商，填写 API Key → 测试连接 → 保存。

- 只支持 OpenAI 兼容接口；地址与模型名称以服务商文档为准。
- API Key 默认只保存在本次会话中；勾选“记住在本机”才会保存到浏览器本地存储，不会写进作品文件。
- 若提示“无法连接（可能是网络或跨域限制）”，说明该服务不允许浏览器直接调用，作品会自动改用离线回答。

## 其他

- **画质**：设置中可选自动、高、中、低。自动模式会按帧率降档；低档关闭泛光效果。
- **海报**：终章完成后点击“生成我的宇宙海报”，右键或长按图片保存。
- **预览倍速**（排练用）：在地址后加 `?speed=4`，例如 `index.html?speed=4`。正式演示不要加。
- **清空记录**：墓园中“清空我的实验记录”只清除你本机的记录，预置的历史实验档案保留。
