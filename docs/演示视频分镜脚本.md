# 演示视频分镜脚本

> 视频时长、分辨率、格式与文件大小以《作品材料提交规范》为准【待核对】。以下按约 3 分半的精剪版设计；如规范允许更长，可直接使用完整导览录屏（约 5 分 30 秒）。

## 录制准备

1. 打开 `dist/index.html`，浏览器全屏，画质设为“高”。分辨率 1920×1080，录屏帧率 60。
2. 录屏软件推荐 OBS Studio（免费，GPL）：输入“窗口采集”，编码 1080p60，码率约 20 Mbps。
3. 导览模式录一遍完整素材；再用自由模式补录特写镜头（见下表“补录”）。
4. 配音由团队成员按 [旁白文稿](旁白文稿.md) 录制，安静环境、单声道 48 kHz。作品内的字幕保留，与配音一致。
5. 作品声音（生成式底噪与事件音）作为背景，音量压到配音以下约 12 dB。
6. 片尾字幕注明：AI 工具使用情况（一句话说明并指向作品说明）、NASA 影像来源、字体授权、团队成员与分工。

## 补录清单

- 第③幕恒温器曲线特写：自由模式，拖动“硅酸盐风化效率”到 0 再回到 1。
- 第④幕撞击特写：自由模式，点击行星朝向镜头一侧的橙色区域。
- 第⑤幕“另一个你”：推演完成后点击按钮。
- 观测者·零号：提问“如果没有月球会怎样”，展示校验闸门与沙盒推演；在线模式若已接入，再录一次并注明“AI 生成”。
- 观测档案的因果图与参数注册表，各停留 2 秒，用于说明严谨性。
