## 制作参数

- 画面：Playwright + Edge 无头模式，以虚拟时钟逐帧推进真实作品，1600×900 CSS 画布、1.2 倍设备像素比，输出 1920×1080、30 fps。
- 解说：Google Cloud Text-to-Speech，`cmn-CN-Chirp3-HD-Charon`，全片统一 `speaking_rate=1.2`；29 条字幕逐句对齐，仅 1 条因 0.09 秒溢出做轻微时间压缩。
- 配乐：`video/score.py` 根据 `film.json` 的章节、参数点击、解锁与撞击事件离线合成。
- 混音：`video/mix_audio.py` 将配乐压低后与解说混合；成片音频 AAC-LC、44.1 kHz、双声道。
- 渲染：`node video/render.mjs`；完整素材位于 `video/out/film.json`、`captions.srt`、`score.wav`、`voice.wav`、`mixed.wav`。

## 优化原则

1. 每一幕只保留一个核心问题、一个真实交互和一个结果镜头。
2. 用画面转场承担尺度变化，用短句解释因果，不再用长段说明覆盖操作。
3. 重要视觉与操作保留完整：地球、K-Pg 撞击、城市夜景、旧分支灰线、真实地球夜面与未来参数。
4. 删除重复的章节卡、重复确认与过长等待；片头从片名直接进入实验室。

初版长版分镜与录制方案保留在 `video/overlay_5min.js` 与渲染脚本历史中，用于补录和后续扩展。
