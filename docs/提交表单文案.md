## 4. 创意来源

选题起于一个常被混淆的问题：宇宙如此广阔，为什么我们至今没有发现第二个文明？我们把它拆成两个问题——物理常数回答“宇宙为什么允许生命存在”，行星、生命与文明回答“银河系为什么一片寂静”。前者可以量化：强相互作用偏移约 0.5%、库仑力偏移约 4%，恒星就几乎造不出碳与氧；后者只能靠逐层筛选与不确定性传播来讨论。

创作动机是把这类“概率极低的奇迹”从文字变成可亲手操作的实验：让观众自己拧动参量，看见链条在哪一层断裂，而不是听一段结论。核心创意是“知识即权限”——理解的层级决定能改变的层级，顿悟之后钥匙才亮起；配合随机宇宙编号与可复现的推演，使每一次体验既独一无二又可核验。视觉上采用程序化行星与全息仪器的东方硬科幻语言；思想上以马克思主义关于自由与必然、历史合力的论述为内核，落在“文明值得珍惜、未来握在每个人手里”。

## 5. 运行环境

**操作系统**：Windows 10/11、macOS 12 及以上、Linux（x86_64）桌面系统。

**浏览器**：Chrome 100+ 或 Edge 100+（需支持 WebGL2），无需安装插件或运行时。

**运行方式**：单个 HTML 文件（约 1.67 MiB），脚本、字体与影像全部内联，双击即可离线运行，全程零网络请求。

**硬件建议**：分辨率 1920×1080 全屏；内存 4 GB 以上；集成显卡可在低画质下运行，独立显卡可开高画质（开发机实测约 59–140 fps）；支持鼠标、键盘与触摸操作；声音由 Web Audio 实时合成，建议佩戴耳机。

**可选联网功能**：在线模式的“观测者·零号”需观众自行填写兼容 OpenAI 接口的服务地址与 API Key；不填则自动使用离线规则与预置回答。
