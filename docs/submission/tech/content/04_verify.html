评审最关心的问题是“它是不是真的在算”。本章给出测试矩阵、性能数据与三条复现命令：从干净的仓库出发，任何人都能在本机重建作品、复算全部数值，并核对本文引用的每一个数字。

4.2可复现性的三道保险

  1. 随机数分流域：core/rng.ts 以「宇宙编号 ⊕ 用途字符串」派生独立随机流。沙盘的拓殖、商路、战争、瘟疫各用各的流，因此新增一个随机事件不会改变其他事件的序列。
  2. 从头重放：沙盘的时间轴回卷不做快照回滚，而是用记录下来的干预日志从第 0 年重新推演。代价是一次重放需要几十毫秒，收益是状态不存在“回滚不干净”的可能。
  3. 文档与图表重算：npm run docs 重新调用引擎，生成参数表、关键数值与旁白文稿；scripts/figdata.ts 导出绘图数据，scripts/figures.py 重绘全部数据图。文档里的数字不是手抄的，是每次生成时算出来的。

4.5已知限制

  • 示意性模型：文明动力学、未来情景与德雷克方程抽样是“机制示意”，用于表达参量的方向与相对大小，不构成对真实历史的预测；作品内与本文均如此标注。
  • 硬件覆盖：集成显卡与移动端的帧率数据仍在采集；低档画质是为这类设备准备的兜底路径。
  • 在线智能层可选：大模型接入需要观众自备 OpenAI 兼容服务与 Key；无网络时功能自动回落到规则引擎，不影响主线体验。
  • 文档图表依赖 Python：数据图由 Python 重绘，若环境缺少 numpy/matplotlib，只能复算数值而无法重绘图片。
