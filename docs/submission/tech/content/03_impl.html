从实验大厅到终章，一条连续的体验路线；每一幕都有一个由引擎驱动的标志性交互。

本章展示作品的体验流程、界面布局与关键交互的实现。

3.1体验流程与叙事结构

作品的情绪曲线经过专门设计：寂静中诞生 → 星光 → 生命的绿 → 文明的灯火 → 灯火熄灭 → 万籁俱寂 → 揭示地球 → 历史合力 → 未来之钥。每一幕内部都是同一个循环：调节参量 → 引擎推演 → 判定这一层能否走过。链条断裂时，文明熄灭并归入大厅外圈的“文明墓园”，留下一句墓志铭；观众可以回溯改写，也可以换一个宇宙重新开始。没有钥匙不会被卡住，而是先看到后果、读完顿悟卡后自动解锁。

本章界面图均为作品实机截图。文档原计划使用的 AI 概念图未采用，已在本版本中删除对应图位；作品运行画面不包含任何 AI 生成的图像。

3.2界面布局

区域内容
顶栏当前章节与进度点；导览 / 自由切换、参数台、观测者·零号提问、观测档案、文明墓园、设置、声音
左侧“文明链条”文明名字与宇宙编号；L0–L5 每层的状态与实时读数；点击标题切换为“参数空间存活比例”视图；已点亮的钥匙
右侧仪器面板当前实验舱的说明、参数滑杆（带置信徽章与出处）、读数、推演结论与“进入下一幕”
底部观测者·零号的字幕；第⑤幕的沙盘控制台（播放、倍速、时间轴、干预工具）与事件流
折叠链条、仪器面板与事件流均可折叠；面板分节点击标题展开 / 收起，次要信息（读数表、长列表、辅助图表）默认收起，选择会被记住；顶栏“收起”或 H 键一键收起全部浮层，只留三维画面
左下角尺度读数：当前画面的空间尺度（对数刻度，10⁰–10²⁶ m）

3.3第⑤幕：交互最密集的文明沙盘

第⑤幕由行星表面俯冲进入一张悬浮的全息大陆。观众可以：

  • 实时调参：在推演过程中拖动合作程度、生态约束、开放交流、制度弹性，历史立刻改变走向；
  • 拖动时间轴回溯：把历史拖回任意一步，从那里开出新的分支，新旧两条历史曲线叠放在仪器面板中对照；
  • 直接干预：传授技术、调停战争、修复生态，或者降下瘟疫、大旱；
  • 核危机抉择：两个核国家开战时推演暂停，由观众决定“等待”还是“发射”；
  • 观察：点击任意聚落查看其档案（人口、所属政体、社会形态、经历过的事件）；点击事件流中的条目，镜头飞到事件发生地；
  • “另一个你”：用初始条件只差百万分之一的宇宙重跑一次，并排对照两部历史。

3.4导览模式与观测档案

导览模式约 5 分 10 秒，按章节依次运行每一幕的导演脚本：镜头运动、字幕、关键参数的演示性调节与顿悟卡片全部由同一个补间调度器驱动，适合展厅大屏循环播放；观众随时可以按空格暂停或切换到自由模式，从当前幕接着玩。

观测档案（快捷键 A）汇总一次旅程的全部记录：文明编年史、名词解释、知识卡、参数注册表、因果图、马克思主义理论对照、方法与声明。在线模式下由大模型生成的内容（文明名字、编年史、回答）均在界面上标注“AI 生成”。
