神经符号协同的 AI 观测者、六层因果筛选引擎、基于主体的微观文明推演、不确定性量化与混沌分析、GPU 程序化实时渲染。

本章逐项剖析作品采用的技术、模型与参数，并给出由作品引擎实测得到的图表。

2.1系统总体架构

作品采用“确定性内核 + 智能外壳”的五层架构。最底层是数据层：一份参数注册表同时驱动界面滑杆、引擎判定、大模型校验、观测档案与本文的附表，从结构上保证“界面上显示的、引擎计算的、文档里写的”是同一组数字。其上是模拟层：全部为纯函数的确定性推演引擎，不依赖界面与渲染，可单独测试。智能层只能通过校验闸门向模拟层提交参数提议，不能直接写入任何数值。表现层与体验层负责把引擎状态翻译成画面、声音与叙事。

2.2神经符号协同：大模型提议，引擎裁决

当前人工智能的一个重要研究方向是神经符号人工智能（Neuro-Symbolic AI）：把神经网络在语言理解上的长处，与符号系统在精确推理、可验证性上的长处结合起来。大模型擅长理解“如果地球离太阳远一点会怎样”这样的自然语言，但它会编造数字；确定性引擎能给出精确、可复现的答案，却听不懂人话。作品的“观测者·零号”把两者组合成一条有分工的流水线，遵循近年“大模型调用外部工具”的范式——大模型只负责提议与讲述，所有数值由引擎裁决。

四步流水线

  1. 意图解析（神经）：系统提示词中包含参数注册表的摘要，要求模型只输出形如 {"intent","changes","rationale"} 的 JSON，把“让地球离太阳远一点”翻译成 orbit_a: 1.5 这样的参数提议。
  2. 校验闸门（符号）：提议必须同时满足五条规则，否则被拒绝并说明原因——参数存在于注册表；不是只读事实；类型正确；在取值范围内（越界值夹回边界并标注）；观众持有对应钥匙。一次最多接受 4 项改动。
  3. 沙盒推演（符号）：在当前状态的副本上运行引擎，得到 L0–L5 的逐层结论；涉及文明层时，同时给出 300 个平行宇宙的存活率。沙盒不影响观众正在进行的旅程。
  4. 检索增强解释（神经）：按字符二元组重合度，从知识卡、马克思主义理论库与相关参数中检索上下文；提示词规定数值只能引用引擎结果、理论只能引用库内的标准表述，防止“幻觉”与曲解原意。
$$\operatorname{score}(q,d)=\bigl|\,B(q)\cap B(d)\,\bigr|,\qquad B(s)=\{\,s_i s_{i+1}\mid 1\le i<|s|\,\}$$

\(B(s)\) 为文本 \(s\) 的字符二元组集合。中文没有空格分词，二元组在不引入分词词典的前提下即可得到稳定的相关度；理论库条目额外按关键词命中加权。

为什么这样设计

闸门是一道“防幻觉防火墙”：即使大模型被诱导输出离谱的参数，也只会得到一条拒绝说明；即使它在解释中想编造数字，提示词与检索上下文中也没有可供编造的来源。没有网络或没有 API Key 时，23 条规则意图与预置回答接管全部功能，带调参的条目同样经过闸门与沙盒——作品在任何环境下都能完整体验。

// 校验闸门（src/llm/schema.ts）的拒绝规则，节选
if (!PARAM_INDEX[id])            reject('注册表中没有这个参量')
if (def.kind === 'fact')       reject('这是只读的事实，不能修改')

2.3知识即权限：认知坐标与名词注释网络

作品把“学习”做成了探索的动力。钥匙集合同时驱动三个子系统：文明链条的亮起状态、参数滑杆的锁定，以及校验闸门的权限规则——这保证了“观众能改什么”在界面、引擎与 AI 三处完全一致。顿悟解锁的讲解文本按五档认知深度分别撰写，同一个现象（例如行星冰封）对小学生讲“离太阳太远，接收的阳光不够”，对研究生则给出辐射平衡方程与反照率反馈。

为了让作品真正“向科普靠拢”，界面中出现的全部专业名词都接入了一张名词注释网络：70 个条目覆盖物理、天文、地球科学、生物、复杂系统、概率统计、马克思主义理论、计算机与人工智能八个领域，每条包含一句话释义、科普解释、在本作品中的应用与延伸阅读。

  • 自动标注：用 MutationObserver 监听整个界面的文本变化，新出现的文字节点按“长词优先”的正则表达式匹配术语（避免“温室效应”被“温室”抢先匹配），包上带虚线下划线的标记；悬停显示一句话释义。
  • 双击跳转：左键双击任一术语，导览自动暂停，观测档案打开到“名词解释”页并定位、闪烁该条目。
  • 零干扰：输入框、按钮、字幕与条目标题本身被排除在外；标注造成的 DOM 变动在同一微任务中被丢弃，不会引发循环。
