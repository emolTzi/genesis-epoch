作品速览

在已知的宇宙里，我们只确认过一次文明。《创世纪元》把“文明为什么如此稀有”做成一座可以亲手操作的 AI 实验室：观众从物理常数一路推演到人类文明，每一次调参都由确定性引擎实时计算，每一次失败都可复现、可核验；而最后一把“未来之钥”，交到每一个人手里。

6层宇宙因果筛选链：物理常数 → 天体 → 行星化学 → 生命 → 文明 → 未来
29项参数注册表：每项含参考值、可行区间、文献出处与五级置信徽章
3168格微观文明沙盘：数百座聚落的耕作、通商、战争、瘟疫与社会形态更替
104宇宙德雷克方程蒙特卡洛：不确定性如实传播，51.6% 的宇宙 N < 1
63项单元测试：公式数值、逐层判定、可复现性、微观与宏观模型一致性
70条专业名词注释：界面中任一术语左键双击即跳转到完整释义与应用
