2.10GPU 程序化实时渲染

作品中没有一张预先绘制的行星贴图，也没有一个外部三维模型：行星、宇宙网、银河系、恒星、文明沙盘上的山川、森林与城市，全部由着色器与程序在运行时生成，并由引擎状态实时驱动。这既让单文件体积控制在约 1.7 MB，也让“参数一变、画面立刻跟着变”成为可能。

程序化行星与大气散射

行星表面由三维值噪声的分形布朗运动（fbm）生成，大陆形状再经一层域扭曲，避免规则的斑块感：

$$\begin{gathered}h(\mathbf p)=\sum_{o=0}^{5}\frac{1}{2^{o+1}}\,n\!\left(\mathbf q_o\right),\qquad \mathbf q_0=2.1\,\mathbf p+\mathbf s,\;\;\mathbf q_{o+1}=2.03\,\mathbf q_o+\mathbf c\\[2pt] \text{陆地}=\operatorname{smoothstep}\bigl(h_{\text{sea}},\,h_{\text{sea}}+0.012,\,h\bigr)\end{gathered}\tag{2-13}$$

在此之上，内陆叠加山脊多重分形形成山脉，并在切平面上对高程做有限差分扰动法线，得到逐像素的地形明暗；群系按气候带分布——赤道雨林、约 ±25° 的副热带荒漠、中纬度森林与草原、高纬针叶林与苔原；大陆架呈浅青色，远洋深蓝，海面带菲涅尔反射与太阳闪烁；云层叠加域扭曲的卷云并在地表投下云影；夜面灯火沿海岸与温带聚集。其中 \(\mathbf s\) 由宇宙编号决定，海平面 \(h_{\text{sea}}\)、冰线、植被、沙漠、失控温室、灰烬与城市灯火都是由引擎结果驱动的 uniform——第②幕把轨道拖远，冰线就在画面上向赤道推进；第③幕恒温器失效，行星就变成金黄色的金星状。大气分三层绘制：表面着色时在日面边缘叠加瑞利式的蓝色散射项 \((1-\mathbf N\cdot\mathbf V)^{2.2}\)；前向的菲涅尔大气壳；以及一层背面渲染的外层光晕，用视线方向法向量 \(n_z\) 计算越过行星边缘的辉光强度 \(I=\operatorname{clamp}(-n_z/0.5)^{1.9}\)，向光面明亮、晨昏线泛暖、背光面幽暗。太阳方向随镜头方位实时调整，始终约有六成日面朝向观众，夜面的城市灯火同时入画。

后期处理与自适应画质

  • HDR 泛光：UnrealBloomPass 的亮度阈值设为 0.82，只有颜色值超过 1 的发光体（恒星、核火球、国界、城市灯火）才会泛光，避免画面整体发灰。
  • 电影级色调映射：ACES Filmic 曲线把高动态范围压缩到显示器范围，保留高光层次。
  • 自适应画质：渲染循环持续测量帧率，连续两次低于 38 fps 自动降一档（高 / 中 / 低）；三档的像素比上限分别为 2、1.25、0.85，粒子数量按 100% / 55% / 28% 缩放，低档关闭阴影并减半植被。移动端默认低档，窄屏界面改为底部面板。
  • 离屏暂停：页面不可见时停止渲染，节省电量。

宇宙尺度连续缩放

镜头从宇宙网一路推进到城市楼群，跨越二十多个数量级而不切镜头。实现上，外层场景按指数放大并淡出，内层场景从 0.02 倍长到原大并淡入，左下角的尺度读数按对数插值：

$$\log_{10}s(t)=\bigl(1-e(t)\bigr)\log_{10}s_0+e(t)\log_{10}s_1,\qquad e(t)=\text{缓动函数}\tag{2-14}$$

完整路径为：宇宙网（约 10²⁵ m）→ 银河系 → 恒星系 → 行星（约 10⁷ m）→ 大陆沙盘（约 10⁶·⁶ m）→ 城市楼群。

2.11可复现性与工程质量

  • 确定性：全部随机性来自以宇宙编号为种子的 mulberry32 伪随机数发生器；模拟层是纯函数，不读取时间、不依赖渲染帧率。导览、补间与等待都由渲染循环驱动的同一个调度器执行，暂停、倍速与跳过对整条时间线一致生效。
  • 测试：63 项 Vitest 单元测试，覆盖公式数值（如地球 \(T_{\mathrm{eq}}\approx254.6\) K）、逐层判定、恒温器负反馈、13% 标定、文明模型的可复现性与单调性、微观沙盘的回溯重放与质变条件、微观与宏观模型趋势一致、跨层耦合（过冷无法耕作、变暖荒漠扩张）、未来模型解析解与蒙特卡洛一致、Lorenz 增长率、校验闸门全部拒绝规则、离线意图匹配。
  • 持续集成：每次推送到主分支，GitHub Actions 依次运行测试、构建与部署，在线版始终与源码一致。
  • 单文件交付：构建脚本扫描源码中实际出现的汉字，把思源宋体子集化到约 416 KB；全部字体、NASA 地球影像与后台线程脚本以 data URI 或 Blob 内联，运行时零网络请求。
  • 数据驱动文档：npm run docs 从源码生成参数注册表与关键数值表；本文的全部数据图由 scripts/figdata.ts 调用作品引擎导出、scripts/figures.py 绘制，任何人都可以复现。
