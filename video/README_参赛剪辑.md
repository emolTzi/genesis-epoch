## 视觉与系统优化

- 地球：真实影像加入色彩分级、双尺度云影、纹理亮度细节法线、窄高光、NASA 夜光城市与海陆掩膜；K-Pg 沉积区由硬边条纹改为分形矿区纹理与边界微光。
- 撞击：新增半球形高温碎片喷流、局部尘埃云与收缩激波；修正闪光与尘埃尺度。
- 文明沙盘：提高城市建筑密度与高度分布，加入类型化楼体色板、夜间道路与窗格照明、夜间环境过渡、全息底座和环境轮廓；人口承载力增加软上限，避免技术后期人口指数失控。
- 终极场：一万宇宙光点改为更密、更亮的簇状分布，增加蓝色样本云光晕和尺寸钳制，避免混入背景星场而不可辨。
- 恒星系：降低恒星光晕和宜居带透明度，保留可读的轨道与宜居带层次。
- 仪表：降低浑天仪过曝，收紧光晕；统一章节卡、字幕、暗角和胶片边缘光。
- 交互与叙事：字幕停留时间按语音时长调整；低合作历史与参数重写历史形成真实对照。

## 渲染管线

```bash
npm run build          # 作品单文件 dist/index.html
node video/render.mjs  # Edge + Playwright 逐帧录制、字幕、配乐、解说与混音
```

渲染时使用虚拟时钟逐帧推进作品，30 fps 连续截图后送入 ffmpeg 编码。`overlay.js` 负责线性叙事、章节卡、光标、字幕与交互调度；`voice.py` 调用系统中文语音合成并按字幕窗口自适应语速；`mix_audio.py` 将语音与 `score.py` 的程序化配乐压混。

完整逐帧渲染在普通桌面设备上约需 40 分钟；预览可用：

```bash
node video/render.mjs --preview --from 0 --to 120 --every 30
```

## 素材与标识

- 作品画面均来自本项目的实际运行结果。
- 地球昼面与夜面影像来自 NASA 公有领域素材（见 `docs/第三方资源清单.md`）。
- 动态图形、字幕、程序配乐与系统中文解说为 AI 辅助生成，已在片尾和 `docs/人工智能工具使用说明.md` 中说明。
